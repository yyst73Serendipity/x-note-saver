Google 账号云同步配置

当前绑定项目：x-note-saver。保持 Spark 免费套餐，不要在配置文件中放入密码、服务账号私钥或 Firebase CLI 登录令牌。

1. 创建 Web 应用

在 Firebase 控制台的“项目设置 → 常规 → 您的应用”中添加 Web 应用，名称填写 x-note-saver-extension，同时勾选 Hosting。复制生成配置里的 apiKey 和 appId。

2. 开启 Google 登录与数据库

在“Authentication → 登录方法”启用 Google；在“Firestore Database”创建 Standard 数据库。位置选离自己较近的区域，并先使用生产模式。

3. 配置扩展

复制 config/firebase.example.json 为 config/firebase.local.json，填写公开客户端配置。运行 npm run build，扩展 ID 会写入 dist/extension-id.txt。

4. 授权扩展来源

在 Authentication 的授权域名中添加 chrome-extension://扩展ID。随后部署 Hosting 登录页，再从管理页登录。

5. 限定个人账号

第一次登录会显示你的 Firebase UID。把它填入 ownerUid，重新构建并部署 Firestore 规则。完成之前，规则会拒绝所有云端数据访问。

6. 加载与迁移

在 chrome://extensions 加载 dist/extension。登录后先下载迁移前 JSON 备份，再确认把旧收藏合并到云端。
