# 收藏管理页 UI 改版设计

## 目标

在不改变现有收藏和同步功能的前提下，重做收藏管理页的视觉层级。页面采用资料库式布局和蓝色主题，让账号状态、分类导航、搜索与帖子内容各自形成清晰区域，同时降低边框、按钮和无效装饰带来的杂乱感。

## 设计方向

- 采用已确认的“安静资料库”布局与中文文案。
- 主题色使用蓝色，冷白灰作为页面和卡片底色。
- 标题可以保留轻微的阅读感，正文、按钮和状态信息继续使用系统无衬线字体，保证中文可读性。
- 蓝色只用于当前分类、同步状态、焦点和关键交互，避免整页大面积铺蓝。
- 账号同步栏保留现有按钮和操作顺序，不增加折叠菜单。

## 色彩与视觉变量

| 用途 | 色值 |
| --- | --- |
| 主蓝色 | `#2563EB` |
| 状态蓝色 | `#3B82F6` |
| 选中背景 | `#EAF2FF` |
| 页面背景 | `#F4F7FA` |
| 卡片背景 | `#FFFFFF` |
| 主文字 | `#111827` |
| 次级文字 | `#64748B` |
| 边框 | `#DFE6ED` |

圆角以 10–14 px 为主。卡片阴影保持轻微，仅用于区分页面层级，不制造悬浮感过强的面板。

## 页面结构

### 顶部标题区

- 标题使用“我的帖子札记”，强化个人资料库属性。
- 顶部右侧继续放置导出、导入和清空操作。
- 清空仍使用危险操作样式和原有确认弹窗，不把危险含义改成普通主按钮。

### 账号与同步栏

左侧按以下顺序展示：

1. 当前 Google 账号。
2. 同步状态，例如“已同步 · 18:29:53”。
3. 存在待上传操作时显示数量，例如“2 项待上传”。

右侧完整保留现有操作：

1. 立即同步。
2. 清除本机缓存。
3. 退出登录。
4. 配置帮助。

同步进行时沿用现有禁用逻辑，只调整禁用色、间距、圆角和文字层级。不同状态继续提供明确文字，不仅依靠颜色表达。

### 左侧分类侧边栏

- 保留“全部收藏”“稍后阅读”“未分类”三个固定入口。
- 保留自定义分类的新建、拖拽排序、重命名、删除和数量统计。
- 新建分类按钮固定在“分类目录”标题右侧。
- 自定义分类的重命名和删除操作在悬停或键盘聚焦时出现，减少常驻按钮造成的杂乱。
- 触摸设备无法悬停时，分类操作按钮保持可访问。
- 当前分类使用浅蓝背景和深蓝文字，不改变已有分类切换逻辑。

### 内容区域

- 搜索框与排序控件位于同一行，搜索框占据剩余宽度。
- 当前分类标题和帖子数量放在搜索栏下方。
- 空状态使用星形图标、简短标题和操作提示：“前往 X，在帖子操作栏点击星形按钮”。
- 有数据时沿用现有帖子卡片内容与操作，只统一边框、留白、标签和按钮视觉。

### 本地缓存信息

- 保留真实缓存大小文字和扩展存储权限状态。
- 移除没有固定上限依据的占用进度条，避免把 `unlimitedStorage` 表达成可计算百分比。
- 缓存信息降级为页面底部的辅助说明，不与主要操作竞争注意力。

## 响应式与可访问性

- 宽屏保持左侧分类、右侧内容的双栏结构。
- 窄屏时分类栏移到内容上方，同步栏和按钮允许换行。
- 所有按钮保留清晰的悬停、键盘焦点、禁用状态。
- 颜色对比需满足普通文字可读性；同步成功、失败和等待状态同时显示文字。
- 不改变现有对话框、确认流程和数据行为。

## 涉及文件

- `manager/manager.html`：调整页面语义结构和文案。
- `manager/manager.css`：重做布局、主题变量、侧边栏、搜索栏、卡片和响应式样式。
- `manager/cloud-panel.css`：统一同步栏、按钮和对话框视觉。
- `manager/cloud-panel.js`：仅在界面结构需要时调整元素绑定，不改变同步业务逻辑。
- `manager/manager.js`：仅在分类操作显隐或无障碍状态需要时调整，不改变收藏数据逻辑。
- `tests/`：补充或更新与页面结构、分类操作和同步栏状态相关的测试。
- `README.md`：完成实现后更新页面使用说明和界面描述。

## 明确不改动的范围

- Firebase 登录、Firestore 数据模型和安全规则。
- 收藏、导入导出、迁移、冲突处理和离线同步逻辑。
- 分类的新建、排序、重命名和删除行为。
- Chrome 扩展 ID、权限和加载方式。

## 验收标准

1. 页面使用已确认的资料库式布局与蓝色主题。
2. 同步栏右侧仍显示“立即同步、清除本机缓存、退出登录、配置帮助”。
3. 分类的新建、拖拽排序、重命名和删除均可正常使用。
4. 同步状态、待上传数量、错误信息和按钮禁用状态仍准确显示。
5. 本地缓存大小仍可见，无固定意义的进度条不再显示。
6. 搜索、排序、帖子操作、导入导出和清空功能行为不变。
7. 常见桌面宽度和窄窗口下均无横向溢出，键盘焦点清晰可见。
8. 自动化测试和构建通过，并在 Chrome 中完成一次管理页视觉检查。
