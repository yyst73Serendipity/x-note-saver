# ✨ Twitter 笔记收藏 (x-note-saver)

Chrome Manifest V3 扩展，用于收藏 X 帖子、整理笔记与分类，并可通过 Google 登录在多台设备间同步。

## ✨ 功能介绍

- 在 X 帖子操作栏一键收藏，按 `tweetId` 去重；再次点击已收藏按钮可补全正文和媒体
- 自定义分类、分类排序、稍后阅读、全文搜索
- 帖子列表左侧提供一帖一刻度的快速导航，可直接定位当前筛选结果
- 为收藏添加笔记和标签，保留并发笔记冲突供手动合并
- 保存页面已展开的帖子正文、作者、图片链接和视频封面，兼容原文上的翻译包装节点
- 未登录时仅保存在本机；登录后通过 Firestore 增量同步
- 离线修改进入持久队列，联网后自动重试
- 账号数据隔离、删除墓碑、跨设备冲突处理
- JSON 导入导出和登录后的本地数据迁移预览

## 🛠 技术栈

- 原生 JavaScript、Chrome Extension Manifest V3
- Firebase Authentication、Cloud Firestore Lite、Firebase Hosting
- Firebase Web SDK 12、esbuild、Node.js 内置测试工具

## 🚀 安装和使用

1. 安装依赖：`npm install`
2. 按 [Firebase 配置说明](docs/firebase-setup.md) 创建 `config/firebase.local.json`
3. 构建：`npm run build`
4. 已经从项目根目录加载旧版扩展时，在 `chrome://extensions/` 点击该扩展的“重新加载”，原有本地收藏会保留
5. 首次安装时，开启开发者模式，点击“加载已解压的扩展程序”，选择 `dist/extension`
6. 打开管理页，登录同一个 Google 账号并确认迁移本地收藏

只使用本地收藏时，可以在没有 Firebase 配置的情况下构建和加载，界面会明确显示“未配置云服务”。

## 🖥️ 页面使用（重点）

### 1. 打开收藏管理页

点击 Chrome 工具栏中的“Twitter 笔记收藏”扩展图标，会打开标题为“我的帖子札记”的独立收藏管理页。若图标没有显示，先点击 Chrome 工具栏的“扩展程序”按钮，再将本扩展固定到工具栏。

管理页使用全屏双栏布局：顶部第一行集中展示收藏数量、Google 账号和同步状态，第二行提供导入、导出、清空、迁移、缓存和配置帮助。左侧分类栏、帖子快速导航和帖子卡片保持连续阅读布局，窗口变大时会获得更多显示空间。

管理页主要包含以下区域：

- **账号与云同步**：查看当前 Google 账号和同步状态，也可以立即同步、退出登录或清除本机缓存
- **左侧分类栏**：查看全部、稍后阅读和未分类内容，点击 `+` 新建分类；自定义分类支持拖拽排序、重命名和删除
- **搜索与排序**：按帖子正文或作者搜索，并按收藏时间排序
- **帖子快速导航**：主区域左侧每条刻度对应一篇帖子，蓝色表示当前可见内容；悬停可查看作者和收藏时间，点击即可定位
- **帖子卡片**：编辑笔记和标签、调整分类、打开原文或删除收藏
- **顶部工具栏**：导出、导入或清空数据；执行清空前建议先导出 JSON 备份

管理页使用蓝色标示当前分类、同步状态和关键交互。页面底部的全宽缓存状态栏显示本机工作副本大小；左侧短色块只表示当前浏览器存在缓存数据，不代表 Firebase 云端存储配额或固定容量百分比。

### 2. 在 X 页面收藏帖子

1. 打开或刷新 [X](https://x.com/) 页面。
2. 扩展会在每条帖子的操作栏中加入“收藏推文”星形按钮。
3. 需要完整长文时，先在首页展开全文，或打开帖子详情页；再点击星形按钮并选择分类。保存时会重新读取当前帖子的正文和媒体，未展开的隐藏内容不会自动抓取。
4. 按钮变为已收藏状态后，记录会出现在收藏管理页中。若旧收藏缺正文或媒体，在 X 中展开对应帖子后，再点击已收藏的星形按钮即可补全，无需删除旧记录。

补全只更新更长的正文、补入图片和缺失的视频封面，保留原分类、笔记、标签、稍后阅读状态和收藏时间；较短的折叠正文不会覆盖已有长文。登录后，补全操作也会进入云同步队列。

图片保存的是在线链接；视频保存的是封面和打开原帖的入口，并非离线视频文件。媒体加载失败、尚未出现在页面，或原帖已删除时，扩展无法从当前页面恢复它们。

**升级后请先在 `chrome://extensions/` 重新加载扩展，再刷新已经打开的 X 页面和收藏管理页。** 旧页面的内容脚本不会因本地重新构建而自动更新。

### 3. 使用 Google 账号同步

1. 在管理页的“账号与云同步”区域点击“使用 Google 登录”。
2. 首次登录且本机已有收藏时，先下载页面提示的 JSON 备份，再确认把本地收藏合并到云端。
3. 页面显示 **“已同步 · 时间”**，表示本机待处理修改已经上传且云端数据已经拉取完成。
4. 离线时可以继续收藏和编辑；恢复网络后扩展会自动重试，也可以点击“立即同步”。

### 4. 在另一台电脑或浏览器恢复

1. 安装依赖、准备相同的 `config/firebase.local.json`，再执行 `npm run build`。
2. 在 Chrome 的 `chrome://extensions/` 页面加载 `dist/extension`。
3. 打开收藏管理页，登录同一个 Google 账号。
4. 等待页面显示“已同步”，原有云端收藏、分类、笔记和标签会自动出现。

> **请认准同步状态：** 登录成功不等于同步完成。只有管理页显示“已同步 · 时间”时，才能确认当前设备已经完成云端同步。

## 🧪 测试

```bash
npm test
npm run build
npm run test:integration
```

Firestore 集成测试使用官方 Emulator 和真实安全规则，不连接生产数据库。

正文和媒体采集另有真实浏览器 DOM 回归测试，不读取个人收藏或生产数据库。已具备 Playwright 运行环境时，执行 `node --test tests/browser/content.test.js`；如该环境不在项目依赖路径，可通过 `PLAYWRIGHT_MODULE` 指定现有模块的入口。也可用 `node tests/browser/content.test.js --html /tmp/x-note-content-tests.html` 生成独立测试页，在浏览器中查看结果，无需新增项目依赖。

## 📦 数据备份

管理页支持导出 JSON。导入时会预览新增、重复和笔记冲突；登录后的首次迁移必须先下载一份迁移前备份。云同步不能替代独立备份。
