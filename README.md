# ✨ Twitter 笔记收藏 (x-note-saver)

Chrome 浏览器扩展，在 Twitter/x.com 页面注入收藏按钮，将推文分类收藏到本地存储，并提供管理页面浏览、搜索、导出导入。

## ✨ 功能介绍

- **一键收藏推文** — 在每条推文操作栏中注入收藏按钮，点击弹出分类选择器
- **自定义分类** — 支持新建、重命名、删除分类，「未分类」为默认兜底分类
- **稍后阅读标记** — 独立于分类的标记，侧栏快速入口 + 卡片一键切换
- **本地存储** — 数据完全存储在浏览器本地（chrome.storage.local），不上传任何服务器
- **管理页面** — 独立管理页面，按分类查看、全文搜索、按时间排序
- **添加笔记** — 为每条收藏的推文添加私人笔记
- **媒体展示** — 收藏时提取推文图片和视频封面，管理页以缩略图展示
- **导入导出** — JSON 格式备份/恢复，导入前展示预览、合并自动去重
- **存储配额提醒** — 管理页底部实时显示本地存储用量，临近上限自动预警
- **已收藏标记** — 已收藏的推文按钮显示实心星标，避免重复收藏
- **正文提取** — 从页面 DOM 提取正文，保留段落结构；长推文需先点开详情页再收藏以获取全文
- **可点击链接** — 正文中的 URL 和 @mention 自动转为可点击链接

## 📁 项目目录结构

```
x-note-saver/
├── manifest.json              # Chrome 扩展配置 (Manifest V3)
├── background/
│   └── background.js          # Service Worker（存储读写、消息路由）
├── content/
│   ├── content.js             # 内容脚本（注入收藏按钮、提取推文数据）
│   └── content.css            # 注入 UI 样式（按钮、选择器、Toast）
├── manager/
│   ├── manager.html           # 管理页面
│   ├── manager.js             # 管理页面逻辑（渲染、搜索、导入导出）
│   └── manager.css            # 管理页面样式
├── assets/                    # 扩展图标 (16/48/128)
└── uidraft/                   # 设计文档
```

## 🛠 技术栈

- Chrome Extension Manifest V3
- chrome.storage.local 本地存储
- 纯 DOM 提取，无第三方 API 调用
- 原生 JavaScript（无框架）

## 🚀 安装和使用

1. Clone 项目到本地
2. 打开 Chrome，进入 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择项目根目录
5. 打开 x.com，即可在每条推文底部看到星标收藏按钮
6. 点击浏览器工具栏的扩展图标，打开管理页面

## 📦 数据备份

在管理页面点击「导出」按钮，可将所有收藏数据导出为 JSON 文件。点击「导入」可选择备份文件，先展示导入预览（新增/跳过条数），确认后合并恢复，自动按 tweetId 去重。
